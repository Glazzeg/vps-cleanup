# VPS Cleanup

Небольшой скрипт для осторожной очистки диска на Ubuntu VPS.

## Запуск

Сначала скачай скрипт и посмотри, что он собирается сделать:

```bash
curl -fsSLO https://raw.githubusercontent.com/Glazzeg/vps-cleanup/main/cleanup.sh
bash cleanup.sh
```

По умолчанию скрипт работает только в режиме просмотра. Для выполнения базовой очистки:

```bash
sudo bash cleanup.sh --apply
```

Перед запуском потребуется ввести `YES`. Базовая очистка удаляет кеш APT, старые записи journald (старше 7 дней и/или сверх 200 МБ) и ротированные логи старше 30 дней.

## Дополнительные действия

Включай их отдельно, только если понимаешь последствия:

```bash
sudo bash cleanup.sh --autoremove  # только показать план APT autoremove
sudo bash cleanup.sh --apply --autoremove
sudo bash cleanup.sh --apply --docker
sudo bash cleanup.sh --apply --caches
sudo bash cleanup.sh --apply --tmp
```

- `--autoremove` показывает план, а перед удалением пакетов ещё раз просит ввести `YES`.
- `--docker` очищает неиспользуемые образы Docker и build-кеш. Docker-тома и контейнеры скрипт не удаляет; Docker может запросить подтверждение.
- `--caches` очищает кеши pip и npm пользователя root. Загружать пакеты позже может потребоваться повторно.
- `--tmp` удаляет обычные файлы старше 7 дней в `/tmp` и старше 30 дней в `/var/tmp`. Перед применением изучи список в режиме просмотра: приложения могут хранить там нужные им файлы.

Скрипт не требует API-ключей, токенов или сторонних сервисов. Проверяй содержимое перед запуском от root и используй только на своих VPS.
