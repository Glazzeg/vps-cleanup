# VPS Cleanup

Интерактивная очистка диска Ubuntu VPS. Скрипт сначала показывает кандидатов на очистку, затем задаёт один вопрос `[y/N]`. Нажми `y`, чтобы продолжить, или любую другую клавишу, чтобы отменить.

## Запуск

```bash
curl -fsSLO https://raw.githubusercontent.com/Glazzeg/vps-cleanup/main/cleanup.sh
sudo bash cleanup.sh
```

Проверка справки:

```bash
bash cleanup.sh --help
```

После подтверждения скрипт очищает кеш APT, удаляет пакеты, предложенные `apt autoremove`, сокращает journald до 7 дней/200 МБ, удаляет ротированные логи старше 30 дней, чистит неиспользуемые Docker-образы и build-кеш, отключённые старые ревизии Snap, кеши pip/npm root, а также старые файлы в `/tmp` и `/var/tmp`.

Скрипт не удаляет Docker-контейнеры или тома. Неиспользуемые образы Docker могут понадобиться при следующем запуске контейнера и будут скачаны заново. Старые файлы в `/tmp` и `/var/tmp` могут принадлежать давно работающему приложению, поэтому перед подтверждением просматривай выведенный список.

Требуются root и стандартные системные инструменты. Скрипт не требует API-ключей или токенов.
